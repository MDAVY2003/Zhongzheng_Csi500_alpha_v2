# 中证500纯多头 Alpha 研究

以历史中证500股票池和 101 价量因子为基础，先做样本内长腿筛选，再对通过初筛的近似因子进行 strict 复核，研究纯多头组合在交易成本后的净超额。

完整实验方案、因子名单与结果集中在 **[实验报告](REPORT.md)**：

- **V3 IS（2018—2022）**：27 因子的 Equal 与 Bucket 55/20/10/15，各列 NDROP3、NDROP5。
- **V3 OOS（2023—2025）**：Top15 与 Bucket 75/15/5/5，各列 NDROP3、NDROP5。

2023—2025 已被使用多次，OOS 结果仅作探索性评价；IS 与 OOS 的组合配置不同，不能当作同一冻结策略的直接对照。

`src/`、`scripts/`、`tests/` 保留研究代码与测试；`reports/` 只保留上述最终结果的小型 CSV 和来源清单。真实市场数据、完整账本和本地研究记录不随仓库分发。
